# 備品の棚卸（スマホ完結版）

スマホのブラウザだけで使う、備品棚卸用のWebアプリです。サーバーやPCは不要です。

- 記録は各スマホのブラウザ内（IndexedDB）にだけ保存されます。このリポジトリには目録・記録などのデータは含まれません。
- 数人で手分けする場合は、ファイル（.txt）をLINEなどでやり取りして合体します。
- Excelの読み書きはブラウザ内で行います（外部ライブラリ・外部通信なし）。

## ファイル
| ファイル | 内容 |
|---|---|
| index.html / style.css / app.js | 画面と処理 |
| xlsx.js | Excel（.xlsx）の読み書き |
| qr.js | 倉庫ラベル用QRコードの生成 |
| sw.js | オフライン用の保存（画面を変更したら `CACHE` の番号を上げる） |
